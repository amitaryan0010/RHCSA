# REDIRECTION

## Standard Input
```
# echo "Welcome to Path4Cloud" > input.txt

# ## stdin (Standard Input)

# echo "Welcome to Path4Cloud" > input.txt

# cat input.txt
Welcome to Path4Cloud
```

Do it again
```
# echo "We are learning RHCSA" > input.txt

# cat input.txt
We are learning RHCSA
```
We can see redirting input again overwritten the previous content. So to avoid this situation, always use `append` mode, means double >> redirection which will append the input under existing content.
```
# echo "Welcome to Path4Cloud \n We are learning RHCSA" >> input.txt
# cat input.txt
Welcome to Path4Cloud
Welcome to Path4Cloud \n We are learning RHCSA
```
But again `\n` did not work which is used for next line but by default `echo` user `-E` options which disables the interpretation of \ backslash.

So use `-e` flag which enables the interpretation of \ backslash.
```
# echo -e "\nWe are learning RHCSA" >> input.txt

# cat input.txt
Welcome to Path4Cloud

We are learning RHCSA
```

## Standard Error
```
# ls rhcsa/ cloud/
ls: cannot access 'cloud/': No such file or directory
rhcsa/:
6  file4.txt  grep_example.txt  myfile  ping.sh  test.txt

(giving the output but also throwing the error, let handle the error)
# ls rhcsa/ cloud/ > output.txt 2> error.txt

# cat output.txt
rhcsa/:
6
file4.txt
grep_example.txt
myfile
ping.sh
test.txt

# cat error.txt
ls: cannot access 'cloud/': No such file or directory
```

## Handle error with find command
```
# find /proc/ -size +10M
/proc/kcore
find: ‘/proc/118980/task/118980/fd/6’: No such file or directory
find: ‘/proc/118980/task/118980/fdinfo/6’: No such file or directory
find: ‘/proc/118980/fd/5’: No such file or directory
find: ‘/proc/118980/fdinfo/5’: No such file or directory

Lets redirect the error to null and get the clean output
# find /proc/ -size +10M 2> /dev/null
/proc/kcore

Redirecting output with error
# find /proc/ -size +10M &> find_ooutput.txt
# cat find_ooutput.txt
/proc/kcore
find: ‘/proc/119081/task/119081/fd/6’: No such file or directory
find: ‘/proc/119081/task/119081/fdinfo/6’: No such file or directory
find: ‘/proc/119081/fd/5’: No such file or directory
find: ‘/proc/119081/fdinfo/5’: No such file or directory
```
